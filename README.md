# Pico Pocket Gameboy

A compact retro handheld console designed for Hack Club Half-Life (Week 1).

## Features
- **Microcontroller:** ESP32
- **Display:** SPI TFT LCD (ST7789)
- **Controls:** 4-Way D-Pad, A/B/Start/Select Buttons
- **Audio:** Passive Piezo Buzzer

## Hardware
Designed using KiCad. Schematics and board layout will be pushed to this repository.
